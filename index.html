À propos

Je m'appelle Saad Benallal, développeur web junior passionné par les technologies du web. Après une première expérience dans le domaine technique en tant que technicien fibre optique, j'ai choisi de me reconvertir dans le développement web afin de transformer ma passion pour la création de sites et d'applications en métier.

J'ai suivi une formation diplômante chez OpenClassrooms, où j'ai pu travailler sur plusieurs projets concrets allant de l'intégration web avec HTML et CSS jusqu'au développement d'applications front-end avec React et la création d'API avec Node.js.
